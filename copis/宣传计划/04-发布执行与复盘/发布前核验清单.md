# 发布前核验清单

## 文案与事实

- [ ] 确认标题和正文属于同一版本；`publish.txt` 中没有内部待办或未替换占位符。
- [ ] 当前 A1–A4 使用课程设计说明口吻，不写“今天课堂”“三次跑偏”“三个傍晚”等未经确认的事实。
- [ ] 所有数字、引语、结果、比较都有来源；没有真实学生引语时不用拟声配音冒充。
- [ ] 教学表达为“AI 引导，孩子思考，共同实现”，同时说清具体分工。
- [ ] 无成绩、能力提升或爆款效果的承诺；没有把个人判断写成平台规则。
- [ ] **全中文规范**：旁白、字幕、画面标注条 100% 纯中文，无英文单词夹杂，专有名词已规范汉化。
- [ ] **双平台差异化文案**：视频号前 2 行具备防折叠独立悬念，含行业圈层探讨切口；小红书版场景化与痛点清晰。
- [ ] **三级 SEO 标签矩阵**：品牌主词、硬件/单片机长尾词、少儿科创高频词三级齐备。
- [ ] **置顶评论预设**：包含本期技术小结与低门槛互动提问，准备于发布后 3 分钟内置顶。

## 图片与视频

- [ ] 本篇图片或视频已实际制作、检查，不能只有制作脚本就标为可发。
- [ ] 示意画面标“课程设计示意”；记录卡标“填写模板，非课堂实测”。
- [ ] 手机缩略图能看清主题，标题不遮住主体；图文和视频封面比例分别检查。
- [ ] 真实素材的授权、儿童意愿和匿名要求已确认，遮挡姓名、学校、定位等个人信息。
- [ ] 视频字幕与配音一致；不因替换画面保留错误字幕；素材没有授权不明的音乐。
- [ ] 涉及供电、轮轴、电机等画面已做安全检查，不把示意内容当成家庭接线教程。

## 登记

- [ ] 按平台检查最终标题和内容限制，不把内部字数建议当成平台规则。
- [ ] 发布后登记链接、时间、标题版本、封面版本和发布人确认。
- [ ] 后台截图去除账号隐私后提供；没有截图或字段时标“未提供”。

## 发布门槛（四项独立，逐项勾选）

- [ ] **技术验收**：成片版本与哈希锁定；全片解码通过；关键帧/ROI 抽检完成。
- [ ] **人工试听**：音画同步、TTS 发音、BGM 平衡已由人耳确认。
- [ ] **全片隐私复核**：已由人逐段看完全片并留痕（复核人、时点、结论）。
- [ ] **发布授权**：操作员明确指示发布/定时；记录指示时点与方式。
- [ ] **叙事验收**（只能人判，不得由技术项推导）：①前 3 秒有画面级钩子或真实结果；②标题承诺在正片内兑现，或明确指向下一集；③结尾给出“值了”的落点。三项任一不成立，不发布。

> 备注（不替代勾选）：若操作员明确接受已知路径风险，单独记 **“已知路径按现状接受（范围：…；时点：…；确认人：…）”**。该备注只表示风险被接受，**不能代替全片隐私复核**，本项仍须保持未勾选，直至真正完成复核。

## 发布事实与去重

- [ ] 两平台均检查同素材去重（成片 hash、标题、定时记录），无残留测试定时。
- [ ] 若怀疑重复：先截图与对账，报告操作员；**未经后台核验确认不得删除/取消唯一线上帖子**。
- [ ] 区分“定时提交”与“实际公开”；主状态与备注按四分法填写。
- [ ] 发布后回填公开链接、平台实际公开时间、条数；未取得写“未提供”。
- [ ] 回执与转述冲突时按证据优先级采信（后台/回执 > 当日日志 > 转述 > 推测），冲突项写进备注。
