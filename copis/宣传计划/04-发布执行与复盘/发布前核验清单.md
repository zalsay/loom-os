# 发布前核验清单

## 文案与事实

- [ ] 确认标题和正文属于同一版本；`publish.txt` 中没有内部待办或未替换占位符。
- [ ] 当前 A1–A4 使用课程设计说明口吻，不写“今天课堂”“三次跑偏”“三个傍晚”等未经确认的事实。
- [ ] 所有数字、引语、结果、比较都有来源；没有真实学生引语时不用拟声配音冒充。
- [ ] 教学表达为“AI 引导，孩子思考，共同实现”，同时说清具体分工。
- [ ] 无成绩、能力提升或爆款效果的承诺；没有把个人判断写成平台规则。

## 图片与视频

- [ ] 本篇图片或视频已实际制作、检查，不能只有制作脚本就标为可发。
- [ ] 示意画面标“课程设计示意”；记录卡标“填写模板，非课堂实测”。
- [ ] 手机缩略图能看清主题，标题不遮住主体；图文和视频封面比例分别检查。
- [ ] 真实素材的授权、儿童意愿和匿名要求已确认，遮挡姓名、学校、定位等个人信息。
- [ ] 视频字幕与配音一致；不因替换画面保留错误字幕；素材没有授权不明的音乐。
- [ ] 涉及供电、轮轴、电机等画面已做安全检查，不把示意内容当成家庭接线教程。

## 登记

- [ ] 按平台检查最终标题和内容限制，不把内部字数建议当成平台规则。
- [ ] 发布后登记链接、时间、标题版本、封面版本和发布人确认。
- [ ] 后台截图去除账号隐私后提供；没有截图或字段时标“未提供”。
