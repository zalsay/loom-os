# 人工发布执行与复盘

与内容制作分开管理；不运行发布脚本，不登录账号，不配置自动任务。

- [发布前核验清单](发布前核验清单.md)：事实、素材授权、配图和复制文案检查。
- [发布记录](发布记录.md)：历史记录与本轮未发布项分开。
- [数据记录模板](数据记录模板.csv)：人工填入后台原始字段，不编造缺失指标。

## 记录规则

先填平台、链接、准确发布时间、标题版本和首图版本，再登记观察时间。24 小时和 72 小时是本批选用的观察节点，不是平台流量周期保证；未发布的内容不填假日期。

曝光、浏览和打开等字段按后台实际名称记录。没有的数据写“未提供”，不要填零；收藏、评论和主页访问等也只在可获得时记录。

如需计算 CTR，先确认分子、分母属于同一统计口径与时间窗口；已有官方显示值也按截图原样登记。不同片长的视频要分开比较，低样本只做观察，不宣称显著结论或算法因果。

评论提问和跨平台复用依实际需要进行。不要为了完成动作清单强行互动，也不声称同步发布能带来固定收益。
