## 安全与维护

- 不读取或迁移 `.env`、`.secrets`、`.workbuddy`、cookies、登录二维码等登录态和内部运行配置。
- 不索引 `node_modules`、`__pycache__`、`.DS_Store` 等依赖或系统缓存。
- 源码索引仅保留现有路径，不执行未知上传脚本或重装依赖。
- 源目录中的版本名不自动代表“可直接发布”；使用前核对文案、画面、字幕和历史发布记录。
- `整理映射.csv` 是本轮生成时的快照，后续新增来源文件不会自动写入。
