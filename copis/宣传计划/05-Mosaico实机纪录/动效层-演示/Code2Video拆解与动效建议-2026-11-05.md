# Code2Video 拆解与织界动效改造建议（2026-11-05）

> 对象：[showlab/Code2Video](https://github.com/showlab/Code2Video)（ICML 2026，MIT，2.2k★）。因 GitHub 直连克隆被墙，改用 GitHub API 拉取 README、`prompts/stage1–4.py`、`src/agent.py`、`src/utils.py` 阅读；未运行其代码，未引入其依赖。

## 一、它到底怎么做出「带动效」的视频

它不是文生视频，而是**用可执行代码画动画**，单位是 Manim 场景：

1. **Planner 出大纲**（JSON）：知识点的分节教学大纲，规定时长与递进顺序。
2. **Storyboard 出分镜**：每节拆成若干 `lecture_lines`（讲解句）+ `animations`（动作描述），一句配一个动画。
3. **Coder 写 Manim 类**：每节一个 `TeachingScene` 子类，强制用 **6×6 网格锚点**（A1–F6）定位，禁止 `move_to()/to_edge()`；讲解句与画面元素**按颜色一一对应**。
4. **自动调试环**：`manim -ql` 真渲染 → 非 0 就把 stderr 喂回模型改代码，最多 3 次；仍失败则重生成整节（`debug_and_fix_code`）。
5. **Critic 用视觉模型看片**：渲染出 mp4 后抽帧给 VLM，返回布局/遮挡/可读性问题，再回炉改代码（`optimize_with_feedback`）。
6. **分节渲染 + ffmpeg concat 拼接**，而不是一条命令渲到底。

真正让它「像 3Blue1Brown」的是三件事：**矢量绘制**（不糊、可缩放）、**锚点约束**（布局不靠感觉）、**逐节可重试的渲染管线**。

## 二、我们现有的差距

- 主体是实拍终端 + 相机，动效只有推镜、聚焦蒙层、字幕淡入；没有矢量图层。
- 关键数字（1353 项、507.250 秒、20% 余量）只能靠旁白念，屏幕上没有可视化。
- 状态推进（测试→产物→审阅→部署）只能靠嘴说，观众容易把四态混成一态——这正是 Team 三家共同点名的最大误解点。
- 单条 `filter_complex` 一次成型，改一处要整段重渲，试错成本高。

## 三、结论：不搬 Manim，搬它的三个设计

1. **代码画动效**（而不是剪辑软件关键帧）：可复现、可参数化、可批量套到每一集。
2. **锚点/栅格约束**：1080×1920 固定为标题带、实拍带、终端带、字幕带、装饰带五区，动效元素只能落在规定区域与网格上。
3. **逐段渲染 + 可重试**：动效层单独渲成透明背景片段，再与实拍 `overlay`，改哪层只重渲哪层。

Manim 本身暂不引入：它要 cairo/pango 等系统依赖，渲染慢，且我们的画面 90% 是实拍；用 PIL 逐帧 + ffmpeg 已能覆盖所需动效，成本低一个量级。

## 四、已落地的动效层原型（可看片）

文件：[动效演示.py](动效演示.py) → [动效层-演示-v001.mp4](动效层-演示-v001.mp4)（6 秒，1080×1920，30fps，纯 PIL 逐帧 + ffmpeg）。

演示三个组件，正好对应下一批四集的需求：

| 组件 | 用途 | 对应集数 |
| --- | --- | --- |
| 数字滚动（0→1353，ease-out） | 把测试总数、耗时、余量做成屏上数字 | EP22 / EP23 |
| 四态状态条 | 测试通过｜产物生成｜离线审阅｜真机部署，只点亮已发生的，「真机部署」恒暗并标「未发生」 | EP22–EP25 全集 |
| 六分区地图 | bootloader/partition table/otadata/factory/ui_apps/system 逐块高亮，标出只审阅了后三块 | EP23 / EP24 |

技术细节：`ease_out_cubic` 缓动、逐帧 RGBA 合成、`ffmpeg -framerate 30 -i f%04d.png` 编码，单帧约 25 ms，6 秒片约 8 秒渲完。

## 五、下一批 EP22–EP25 的动效方案

统一加一条**动效轨**（0–2 个组件/集，不叠加，避免花）：

- **EP22**：测试数字滚动到 1253 → 切到「21 次打包 / 1 次 exit2」的两格对比条，第二格闪红。
- **EP23**：数字 1353 + 时长 507.250 s 滚动 → 四产物四个方块依次落位（app 6.59 MB / UI 2.78 MB / system 3.05 MB / 余量 20%）。
- **EP24**：六分区图上只点亮 factory/ui_apps/system → 旁边一个「flash 命令：0 次」计数器，从 0 起就不再动。
- **EP25**：状态条走到「真机部署」前停住并变红，打出「缺：完整 NOR 备份 / NAND 恢复路径 / OTA 备用槽」三行清单，逐行出现。

统一规范：动效只用金 `#FAC864`、白 `#F8FFF8`、暗底 `#283840`、警示 `#FF9678` 四色；每个动效不超过 2 秒；进入用 ease-out，退出不做动画（直接切）。
