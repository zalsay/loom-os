# EP09 制作要点（2026-10-26 定稿，供后续集复用）

> 本集从"素材在远端"到"成片定稿"的完整链路与参数记录。后续 EP 制作直接按本页执行，避免重走弯路。

## 1. 素材链路（远端 → 本地）

1. **原片位置**：执行记录 `EP04…/执行记录/<session_id>/原始素材/*.mov`（Otty 屏 + MAC 相机双路，无音轨）；session 原片**永不修改/删除**。
2. **远端转码**：历史工具 `tools/batch_compress_mov.py` / `compress_otty_recording.py` 会删除原片，不能直接用；`avconvert` HEVC 预设码率失控（中间产物超原片），也不可用。
3. **现行方案**：远端装 static ffmpeg（`/tmp/ffmpeg9/ffmpeg`，osxexperts.net ARM 版，evermeet 只有 x86；远端可直连下载），按项目定稿参数**定点抽段**：
   ```
   ffmpeg -ss <start> -t <dur> -i <src> -map 0:v:0 -an \
     -vf "fps=30,pad=ceil(iw/2)*2:ceil(ih/2)*2" \
     -c:v libx264 -preset veryfast -crf 26 -pix_fmt yuv420p \
     -threads 2 -movflags +faststart -y <out.mp4>
   ```
   输出放 `批量转码/<日期>-<ep>-<session>-segments/`，单段实测 ≤2.1M（40s 成片素材合计 4.2M，满足"≤10M/段"要求）。
4. **调查帧**：同一 ffmpeg 全量解码抽帧（tty 1/10s、相机 1/5s，720w JPEG），用于时间轴定位与隐私排查（cam-w3 有人臂入镜→弃用的判定即来自此）。
5. **拉回**：rsync（--include 白名单），本地放 `剪辑/素材/147-segments/`。

## 2. 画面裁切（聚焦设备）

源分辨率：Otty 1452×1058 / 相机 1392×832（FaceTime 录像自带黑边，内容区实测 x52-1340 / y36-758；设备主体 x547-914 / y0-733）。

| 用途 | 裁切参数 |
| --- | --- |
| 封面照片区（1080×800） | `crop (320,100,800,593)` |
| 成片顶部设备通栏（1080×608） | `crop=835:470:312:90` → scale 2160:1215 → zoompan |
| 成片中部设备镜头 | `crop=810:600:325:133` → scale 1080:800 |
| 中部 tty 特写/宽景 | `crop=1200:889:126:169`（宽）或 `crop=900:667:126:330`（结果行特写） |

要点：**先抽全分辨率帧实测主体范围再定 crop**，不要沿用上一集坐标。

## 3. 字幕与标注（本集修正后的规范）

- **字幕位置**：tty 画面底沿 1320，字幕区 1320–1513 深色空带，`pos(540,1495)`（底锚）。EP08 式"字幕压 tty 底部空区"仅当裁切本身留空时才成立；EP09 裁到源 y1058（满屏测试文字），必须收短画面。
- **实现**：`[mid]crop=1080:712:0:44,setsar=1[midc];[b1][midc]overlay=0:608` ——注意 ffmpeg 写法：**先 `[mid]crop=…[midc]` 再 overlay**；`[a][b]crop=…` 会报错（crop 吃两个输入）。
- **样式**（参考 EP08 v001）：
  - `Cap` 54px 暖白 `&H00FFFFFF`，描边 2.2；
  - `Gold` 62px 暖金 `&H0064C8FA`（即 RGB 250,200,100），描边 2.4，用于**每集 1–2 句重点**（本集：开场句 + 结尾句）。
- **标注条**：112px PNG @ y=1140，`> / $` 前缀，0.3s alpha 淡入淡出；**事实类标注优先**（快进、主机确认、mock 边界必须上标注条）。
- **bottom-strip**：Logo 实占 y1513–1880（通用资产，无集数字样，可跨集复用）；字幕区必须在其上方收笔。

## 4. 标题区（titles.ass）

- Badge 40px 青 + T1 74px 暖白 + T2 96px 暖金，全片常驻；
- **成片 T1/T2 必须与封面同版本**（本集曾出现成片 T2 落后封面一版，已修）。

## 5. 旁白与 BGM

- 旁白：`clone_tts9.py`（MiMo mimo-v2.5-tts-voiceclone，系列自录音色样本，整篇一次合成，不拆句）；文本与分镜逐句锁定，数字必须与验收记录一致。
- BGM：`synth_bgm_ep09.py`（EP08 v2 配方：120BPM 亮琶音+全 8 分 hi-hat，CYCLES=3 出 48.5s 长料，渲染时 atrim）。
- 混音定稿公式：`loudnorm=I=-14:TP=-1.5:LRA=11` + `alimiter=limit=0.80`；旁白 `highpass 100 + adelay 300ms + volume 1.15`。
- 环境：numpy 用 `/opt/homebrew/bin/python3`，PIL 用默认 python3（或 pip `--user --break-system-packages` 补齐，本机二者已齐）。
