# Mosaico 实机纪录系列

启动日期：2026-10-15  
项目主线：从设备到手，到固件、Loom OS、应用和课程验证真正跑起来。  
内容受众：关心孩子动手、AI 参与方式和真实教育产品过程的家长；技术细节服务于故事，不让代码画面变成无意义的录屏。

## 系列叙事

这不是“展示一块开发板”，而是记录一套设备如何被做成孩子可以提出问题、设计、测试和修改的工具。每一集只回答一个问题，并保留真实的失败、等待和下一步。

当前起点：Loom OS 已有 0.1.1 集成候选与主机侧测试记录，Mosaico 于 2026-10-15 到货，真机验收尚未完成。因此系列讲的是“已有软件进入真机验证”，不是“今天才开始写全部代码”，也不是“课程设备已经可用”。

## 每集产物结构（2026-10-19 起）

每集一个目录（如 `EP03-开发纪实/`），发布成品统一放 `产物/`：

- 成品视频（当前推荐版本的 mp4）
- 封面（1080×1440 竖版 PNG）
- 发布文案.md（标题、简介、话题、发布建议、事实边界）

过程版本（v001-vN）与剪辑记录留在当集 `剪辑/`，不混入 `产物/`。

## 每集固定结构

1. **3 秒内提出问题**：今天要验证什么？
2. **展示现场**：真实设备、代码、工具或记录，不先给结论。
3. **做一次动作**：拆、写、编译、烧录、启动或测试。
4. **展示结果**：成功、失败、报错或还没完成都如实记录。
5. **解释意义**：这一步为什么和孩子的探索课堂有关。
6. **留下下一问**：引到下一集，不承诺尚未验证的能力。

## 发布版本

- 主版：45–60 秒，9:16，适合小红书和视频号。
- 预告版：15–20 秒，只保留问题、一个动作和下一集悬念。
- 资料版：保留较完整的代码、日志和测试过程，供项目记录，不直接当作宣传片。

## 角色分工

### 用户现场拍摄

- 操作 Mosaico、电脑、固件、烧录和测试工具。
- 按拍摄单固定机位录制，不为了好看重演真实结果。
- 口述当天真正做了什么、出现什么问题、下一步是什么。
- 交付原始视频、代码版本、日志和拍摄备注。

### Copis Agent 后期与内容

- 先根据素材整理事实清单，区分已验证、待验证和示意内容。
- 设计标题、封面、分镜、旁白、字幕和不同平台文案。
- 剪出主版、预告版和必要的资料版。
- 检查字幕、音频、画面可读性、儿童隐私和技术表述。
- 根据用户提供的发布截图复盘下一集，不执行登录、发布、评论或数据抓取。

## 真实性规则

- 没有日志或画面支持，不写“已成功”“稳定运行”“首次完成”。
- 没有真实原话，不给孩子加引号或用配音冒充孩子说话。
- 示意画面必须标注“课程设计示意”或“流程示意”。
- 代码画面只展示必要片段，密钥、Wi-Fi、设备序列号和账号信息必须遮挡。
- 硬件安全由现场成人把关；视频不把接线画面剪成可照做的家庭教程。

下一集的完整拍摄要求放在对应集目录；所有新集按 [拍摄计划模板](拍摄计划模板.md) 创建。

每集拍摄依赖用户现场操作和素材交接，不创建定时拍摄或无人值守发布任务。先验收当集素材，再按真实开发进度开下一集，不为凑发布频率安排危险操作或重复刷机。
