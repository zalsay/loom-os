## 实际看过的画面（片内时间为近似抽帧位置）

- 174 终端 75 秒：USB 初始化错误与 abort 可见；同时画面中的原始扫描器误标 `app_started`，与独立验收纠偏不一致，不得将其作为应用启动成功或功能通过。
- 177 终端 45、75 秒：大量重复模拟复位、错误与结果汇总。画面含本地用户名和路径等，需审查与必要遮蔽；不能将模拟复位说成实体设备重启。应用主体启动的准确视频位置尚待逐帧定位。
- 178 终端 45、75 秒：错误与结果汇总，含模拟板型及 HMAC 未绕过等字段；不以这张密集结果画面证明所有细节。
- 179 终端 45 秒：模拟器重新启动及日志；75 秒：结果汇总可见 `board_check_passed` 与 `hmac_calculation_returned_ok`，也有连续错误、公开测试密钥及 production_auth_verified=false。应结合日志及验收记录解释，不能称生产认证通过或设备健康启动。
- 179 相机 60 秒：设备画面非常暗，仅旧 Works / Loom Preflight 页面可辨；不是新固件或模拟器 UI。其余相机素材尚未逐段观看。

已抽取各终端 15/45/75/105 秒及四路相机60秒，但以上仅列实际打开目视的帧；抽取不等于已经看过。尚未逐段观看全部素材或完成全片隐私审查，也未核实可剪片段的完整时间区间。设备/终端应严格保持来源和模拟标签，避免旧设备画面造成误解。仅就现有抽帧，素材支持继续设计，但竖屏终端密集细字需按既定重点行聚焦机制做可读性验证；不等于成片可发布。

## 已核对的事实边界

174 USB 包装层初始化失败未进入真实应用主体；177 进入真实应用主体但模拟板型检查失败；178 合成板型检查通过后停于 HMAC 用途检查；179 用公开测试 key 的模拟夹具通过真实 HMAC 初始化，之后触摸 I2C 探测失败、NAND ID 0xff、touch mux 初始化失败。以上来自原 session 验收记录与有限抽帧，未代表实机刷写、生产认证、健康启动、物理触摸或 Runtime 验收通过。
