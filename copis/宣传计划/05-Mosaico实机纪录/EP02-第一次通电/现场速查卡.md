# EP02 第一次通电｜现场只看这一页

## 今天拍什么

设备第一次上电：能不能安全启动、屏幕亮不亮、触控有没有反应。成功失败都拍，不重演、不演示联网和对话。

## 通电前（安全第一）

- 先看官方说明书：供电规格、接口、按键位置；用合规电源，不用不明充电头。
- 出现发热、异味、冒烟、异响：**先断电，再管镜头**；停拍并向售后核实。
- 序列号、二维码、Wi-Fi 信息提前避开画面。

## 开拍前

- 手机竖放固定，1080p/30fps，锁曝光对焦，试录 5 秒回放。
- 桌面清干净，灯从侧前方打；录 10 秒环境底噪。

## 按顺序拍

| 顺序 | 你做什么 | 必须保住什么 |
| --- | --- | --- |
| S01+S02 开场，必拍 | 设备、通电线、说明书同框；近景指认 Type-C 口和按键 | 画面稳定，不确定的接口不口述名称 |
| S03 首次上电，**最重要** | 插线/按电源 → 等待 → 屏幕亮或不亮 → 初始画面稳定，**一条连续长镜头** | 全程不停机、不重演；亮/不亮都是有效素材 |
| S04 屏幕近景，必拍 | 启动画面/初始界面拍清楚 | 不怼屏拍闪，反光就调角度 |
| S05 触控按键，必拍 | 各操作一次，动作前停 1 秒 | 有没有反馈都如实记录 |
| S06 版本，选拍 | 有入口就读固件/系统版本 | 读不出就跳过，写「未读出」 |
| S07 结束画面，必拍 | 屏幕亮起的设备静置，手离开 | 稳定 3 秒以上，留给封面 |
| 照片口述，选拍 | 「设备+通电线+说明书」静态照；一句真实感受 | 只讲实际发生的 |

失败分支：不亮/报错 → S05–S07 改拍失败状态和报错画面，断电，本集以「这一步还没过」收尾。
