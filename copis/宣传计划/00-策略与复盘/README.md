## 一、文档职责与优先级

1. **用户最新明确指令**优先；真实性、隐私、设备操作授权不能被 AI 多数票覆盖。
2. **现行流程**：[运营工作流手册](运营工作流手册.md) 管工作步骤；[AI团队协作手册](AI团队协作手册.md) 管角色与决策权限，两者分工互补。
3. **专业约束**：[事实依据与素材边界](事实依据与素材边界.md) 管证据；[剪辑与音频规范-实机纪录](剪辑与音频规范-实机纪录.md) 管制作。规范中的分集参数仅适用于对应素材，不自动成为所有集的固定值。
4. **单集决策**：用户确认后的最后一轮裁定覆盖此前草案；评审意见、用户确认、成片验收、平台实际发布必须分别登记。
5. **历史材料**：策略讨论、原始输出和数据复盘用于追溯；不能因文件较新、标题含“定稿/终审/共识”就自动当作有效政策。引用历史建议前先检查顶部状态说明。

### 保留为待核事项，不擅自裁定

- **小红书长期频次**：早期文档分别写每周 2–3 篇、3–4 条及日更；当前按用户逐期双平台安排执行。19:30 只解决发布时间，不能单靠该规则推导长期产量配额。
- **数据原始口径**：10-20“净掉粉 1”缺账号新增/取关证据；10-21 同文 EP05 已发/草稿并存；上午关注者 0 与下午主页 8 的差异不证明具体涨粉时点。保留原数并标明待核，不改成猜测值。
- **EP10 实体设备映射**：HTTP 接收实例的上传读回不自动等于实体设备存储/触摸/运行验收；原始评审提出的映射证据仍须查对应执行记录，本次不补造结论。
- **发布技术文档的外部联动**：本次未修改目录外的两份 CLI 发布文档及单集发布物料。其中旧话题方法、固定截图缩放倍率、所谓“合成点击盲区”、首评“下一集就点它”等，应另按实际证据对齐；不能把一次未成功写成工具永久不支持。
- **自动任务**：历史“20:30 自动回拉”只证明曾有该执行记录，不证明目前仍启用；本次没有查询、创建或变更自动任务。
