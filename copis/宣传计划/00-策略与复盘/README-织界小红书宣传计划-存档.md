# 织界小红书宣传计划

> 【存档 2026-10-22】原来源目录 README，随目录合并存入本处。文内 `notes/`、`content-plan.json` 等链接自归档起即失效，仅作历史参考；现役入口见 ../README.md。

面向小学三至六年级孩子的妈妈，以孩子已有的兴趣、零基础起步和AI参与方式为切入点，介绍织界如何组织自主探索。首组系列名为“妈妈关心的事”，包括3篇笔记、9张配图、完整正文和话题。当前状态为待发布素材，后续结合课程进展持续更新。

课程名称为**织界**，代码项目名称为**Loom OS**。统一教学表达是**AI 引导，孩子思考，共同实现**。

## 受众与内容定位

- 关注孩子动手兴趣，希望知道积木、小车或种植还能怎样继续探索的妈妈。
- 希望了解零基础孩子如何参与，以及怎样看见探索过程的家长。
- 关心AI在课堂中的作用，希望了解孩子是否仍在主动提问、选择与验证的家长。

从家长熟悉的具体问题展开，提供可以用于亲子交流的引导问题，再介绍织界的课程方式。孩子负责提问、判断、设计、测试和调整；老师与AI提供问题、反馈和实现支持。

## 统一图文设计

- 配图为1086×1448像素、3:4竖版PNG，每篇3张，按第1张至第3张顺序使用。
- 深色纸纹背景、暖白与暖金标题、青蓝笔触，沿用织界定稿Logo。
- 固定系列名、篇号和页码，妈妈与两位孩子为统一插画人物。
- 插画均标注“课程情境示意”。小车、种植和课堂情节作为课程设计示意呈现。
- 内容页突出可以使用的具体问题、起步步骤和观察点。
- 底部固定“AI 引导 · 孩子思考 · 共同实现”。
