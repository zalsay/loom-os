- **纯中文硬防线**：旁白、自制字幕、顶部标题带与后期说明条 100% 采用纯中文（杜绝英文专有名词与电报体），原始机录终端英文客观保留为来源证据。发布文案严格遵守《04-发布执行与复盘/README.md》的双平台文案与三级 SEO 标签规范。

### 封面标题规范（1080×1440，参数以定稿脚本 make_cover.py 为准）

封面是对外第一眼，**必须逐项对齐系列模板**，禁止自由发挥。字体/字号/颜色以下表为权威（EP04/EP05 成图像素实测值是渲染近似，两者冲突时以本表为准）：

| 元素 | 字体 | 字号 | 颜色 |
|---|---|---|---|
| 徽章行（织界创造日记 · EPXX） | Hiragino Sans GB **W3**（ttc index 0） | 42px | 亮金 #FAC864 (250,200,100) |
| 主标题（line1） | Hiragino Sans GB **W6**（ttc index 2） | 96px | 暖白 #F8FFF8 (248,255,248) |
| 副标题（line2） | Hiragino Sans GB **W6**（ttc index 2） | 140px | 亮金 #FAC864 (250,200,100) |

1. **结构**：头部深色纸纹区 ~640px（噪点 + 6% 大 Logo 底纹）+ 照片区 800px（暗角聚焦设备 + 顶部渐变融入）+ 底部 120px Logo 条。**背景 #283840 深青灰**（与视频背景一致，EP06 v010 曾误用 #1A262D）。
2. **徽章行**：「──  织界创造日记 · EPXX  ──」，W3 42px 亮金，文字带 y 94–131；徽章下 **200px 居中短金线**（y≈167，3px 厚）是模板元素。徽章用青蓝色 = 偏差（EP06 曾犯）；**徽章不带投影**。
3. **标题两行投影（定稿必有）**：主/副标题均带 **3px 偏移、模糊 3 的黑色投影 rgba(0,0,0,160)**（EP06 v010 曾漏）。两行均水平居中。
4. **字号按字数自适应**：`min(基准字号, 1000/字数)`（版心宽 1000px），如 9 字 T2 缩到 111px。
5. **T2 下方不加任何分隔线/装饰**（EP06 曾加长分隔线 = 偏差）；徽章下短金线是唯一装饰线。
6. **封面 T1/T2 文案 = 成片大标题 T1/T2，逐字一致**（EP06 封面曾写「我先摸个底」而成片是「我先在电脑上摸个底」= 偏差）。T1 承接上集悬念、T2 点本集事件，第一人称。
7. **验收**：渲染后逐像素测量文字带位置，与 EP04/EP05 基准（徽章 94–131 / T1 214–303 / T2 365–495）比对，偏差 >6px 判不合格；并核对字体 index（W6 必须显式 `index=2`，ttc 默认 index 0 = W3）、投影存在性、背景色值；与前一集封面并排目检一次。

### PIL 与 ASS 坐标分离

- PIL `text((x,y))` 的 y 是 ascender 顶缘语义；ASS `\pos(x,y)` + `Alignment=8` 是 libass 顶中锚点。**同一个数字在两种渲染器里不落在同一像素行**，禁止直接搬运坐标。
- 改完必须做像素行带实测，与 EP06 基准比对：Badge 62–91、T1 129–183、T2 198–270（EP07 实测 199–270，偏差 ≤1px）。
- ASS 颜色是 `&HBBGGRR`：#FAC864 → `&H0064C8FA`，#F8FFF8 → `&H00F8FFF8`；不要按 RGB 顺序填。

## 2. 旁白与 TTS

- 音色：MiMo voiceclone（`mimo-v2.5-tts-voiceclone`），克隆样本 = EP05 旁白成片 full.wav。
- **字数按片长反推**（目标 4.4 字/秒），不留「片尾空转」；电报体（短句连发）= AI 腔，禁止。
- instruction 用「正常偏快」；首摇偏慢就存档 take 后调 instruction 重摇，不要硬 atempo 拉长。
- 流水线：整篇 TTS → 本地 Whisper（base, zh，隔离 venv）验证无漏句并取分段时间戳 → `atempo ≤1.2` 精确校速（只往降速方向调，质量无损）→ 字幕轴 `caps.json` 程序化生成（按 whisper 时间戳、切点随段落边界）。
- **同一集只使用同一次整篇 TTS take**：禁止逐句分别生成或混拼不同 take；分镜/字幕切点只从这条完整音轨无损切分，避免音色/语速漂移。
- 每次合成存档 take，不覆盖。

## 3. BGM（EP06 v014–v016 教训，最重要）

- **BGM 原文件必须随项目归档**（各集 `剪辑/bgm-upbeat2.wav`），绝不放 /tmp——系统会清理，EP04–EP06 为此返工三轮。
- **禁止用「配方重合成」替代原文件**：各集 BGM 是每次独立合成的不同波形（EP04 与 EP05 成片同位置相关系数仅 0.07），重合成必然听感不对；丢了只能从历史成片反解。
- **从成片反解 BGM**（`recover_bgm.py`，EP06 v016 已验证）：
  - 前提：旁白分轨与成片相关性 **≥0.99** 才可用（EP05 分轨被重录覆盖、仅 0.72，不可用；EP04 分轨完好 0.993）。
  - 方法：混音链线性部分用同款 ffmpeg 滤镜重建纯旁白轨 n(t) → 逐帧最小二乘估计 loudnorm 慢变增益 c(t)（中值滤波去限幅毛刺 + 0.5s 平滑 + 两轮迭代把 BGM 计入参考）→ `b = (out − c·n)/(0.35·c)`。
  - 陷阱：**只除一次 c**——再多除一次会把 loudnorm 增益呼吸反向印回 BGM（RMS 比 1.29 → 修正后 1.04）。
  - 验收：旁白区/干净区短时 RMS 比 ≤1.1；4–8kHz 齿音带残留远低于 BGM 本体；干净区频谱质心与目标成片真实 BGM 一致（EP04 反解 2077Hz vs EP05 实测 2153Hz，同配方）。
- 混音公式：`[bgm]atrim=0:<片长>,volume=0.8,afade=t=out:st=<片长-2>:d=2` → 与旁白（各段 `adelay=<ms>|<ms>,volume=1.15`）`amix=inputs=N:duration=longest:normalize=0` + `aformat=channel_layouts=stereo` + `loudnorm=I=-14:TP=-1.5:LRA=11,aresample=44100,alimiter=limit=0.80:level=disabled`。**volume 0.8 为定稿**（历史 EP03–EP05 用 0.32–0.4 偏轻）。
- 校准敏感点：**片头 intro 是响度基准**（旁白未进、纯 BGM），换 BGM 源后先量 intro mean_volume 再渲片。

## 4. 竖版画面（1080×1920）

- 版式：上半设备画面 608px + 下半 Otty 终端 800px + 底部装饰条（Logo 水印 5% alpha + 小 Logo 92% alpha）。
- 相机紧裁对准设备（EP06 定稿 `crop=640:360:440:100`）；**改裁切框必须同步重算 zoompan 中心**（EP06 曾因漏算偏右丢左侧设备）；源坐标用 drawgrid 网格实测，勿目测缩放图。
- 标题条：0–250 实压暗（alpha 226）+ 250–330 渐变——亮画面下渐变遮罩不够，必须实压暗带。
- **Otty 聚焦循环（v014 定义）**：`in<fin` 全画幅 1.0 → 24 帧 ease-out 推进 zmax（act1/2 用 1.30，含 HOST 行的幕上限 1.05 保整行——HOST 行 709px，zoom>1.05 必截断）→ 保持 → N−69 起 24 帧 ease-in 缩回；蒙层 alpha 170 同步淡入淡出（105 无聚焦感、215 太暗）；聚焦目标必须是**短行**。
- **zoompan 必须显式 `:fps=30`**：默认 25 的陷阱，v011 两侧都漏、双双 25fps 侥幸混过 xfade；v012 混链后 25 vs 30 直接报 `Failed to configure output pad on xfade`。xfade 输入两侧的帧率/timebase 必须一致，排查用 showinfo 看协商属性。
- **终端「图片轮播感」修复**（EP06 v012–v013 定稿）：
  - 先用 YDIF 扫描找真实运动段：`crop=<终端区>,fps=1,signalstats,metadata=print:key=lavfi.signalstats.YDIF`；YDIF=0 = 视觉等同图片，必须避开。
  - 真实滚动太短就用 `setpts=Nx*PTS` 慢放铺满，**按幕边界重新分配慢放映射**：act1/act2 首尾帧源时间必须连续（act1 末帧源 ≈ act2 首帧源），且**下摇/镜头运动必须与打印同步**——运动期间内容不动就又退回图片感。
  - 下摇用 crop y 随 **n 帧号**缓动：`crop=W:H:x:'D*(1-pow(1-min(max((n-A)/B\,0)\,1)\,2))'`（用 n 不用 t，避免首帧 t=NAN）；运动幕**去掉蒙层**（固定暗带会压住正在打印的内容）。
  - 慢放打印流程：预渲染 `ffmpeg -ss <起点> -t <源时长> -i OTTY.mov -vf setpts=Nx*PTS -r 30 -crf 16` 后抽帧验证内容时间线，再接入渲染。
- 每版验收：抽帧 ≥5 个点位（含每分镜中点+片尾）+ otty 区 YDIF 运动量检测（打印段 >1、运动段 >15 为正常，全程 0 = 图片轮播）。
- 同一段录屏不同 `-ss` 切片内容位置可能不同（任务未跑完时），多幕取素材前先确认内容稳定。
- **相机 crop 与 zoom 联动（EP07 v004 定稿）**：`crop=640:360:440:100 → scale=2160:1215 → zoompan z=1+0.08*(1-pow(1-min(in/150,1),3))，x/y 中心 962/783 → 1080×608`。改裁切框必须同步重算 zoom 中心；不要退回近全画幅 `crop=1275:718:57:52` 再下移。验收时在 1.08× 保持态检查屏幕下缘：EP07 原片屏幕玻璃最低点 y≈453、裁切下沿 y460（源图余量 7px），映射到成片 y≈598、距相机区下沿 608 约 10px，不得截断。
- **输入素材一旦变更，必须全量回归，不得只验改动点**：重录/换剪源、改裁切、改缩放、改帧率、改标题层、换 BGM/take 中任意一项，都要按「解码 → 帧数/时长 → 标题行带 → 相机取景（1× 与保持态两处）→ 标注层出现/保持/退出 → 音轨双指纹」整链重跑；只测被改的那一项等于没测（EP07 曾按旧帧号抽检、换了源片段后帧位漂移）。

## 5. 音频验证三件套（交付前必查）

1. 声道数：立体声（24kHz 素材禁直通，须重采样 44.1kHz）。
2. 采样率：44100/48000。
3. `volumedetect`：max_volume ≤ −1.5dB 无削波；intro 段（0–0.45s 纯 BGM）单独量响度。
4. **音轨指纹双口径**：必须分别记录并注明是哪一种，禁止混写。
   - 解码 PCM md5：`ffmpeg -v error -i <成片> -map 0:a:0 -f md5 -`（EP07 `3b1cf8bacd7eba09cfc0aeb5d2367527`，用于跨版本听感一致性）。
   - ADTS 裸流 md5：`ffmpeg -v error -i <成片> -map 0:a:0 -c copy -f adts - | md5`（EP07 `50a128e1db5c671246d78d6b49cd0b88`，398,538B，用于容器/包级一致性）。
   - 报告只写“音频流 md5”而不注明口径，视为记录不完整。

## 8. 后期标注层与证据区分（EP07 v003–v007 沉淀）

- **三套时间窗**：oldlog 0–6.2s（5.8–6.2s 淡出）、focus 6.2–10.2s（6.2–7.0 淡入、9.4–10.2 淡出）、pending 10.28–16.37s。每套都要做进入/退出边界帧回归：5.9s/6.3s、10.2s/10.5s、16.3s/16.5s。
- **视觉语言**：统一终端 Prompt 风格——深底 `rgba(13,21,25,0.92)`、1px `#5C8A94` 细边、青蓝提示符（`>` / `$`）、浅灰 `#C8D2D8` 正文、可选块状光标；**标注层禁止金边、金字**。
- **标注内容必须可实证**：每条后期说明里的数字、状态、事件，都必须能在**同一帧画面**或**其他可靠来源记录**（执行日志、后台回执、素材文件）中指认出来。
  - 同帧可指认 → 直接标注；同帧不可见但有可靠来源 → 可用，但必须**标明来源**（如“日志：…”），不得伪装成画面内证据。
  - **连来源也没有的数字、结果、事件，任何渠道都不得作为事实发布**——口播、发布文案、置顶评论同样禁止；不得用“转口播/写进文案”规避证据要求。
  - 推测必须明确标注为**推测**，不得与已证实事实混写。
  - EP07「历史 94/95 日志，非本轮结果」之所以成立，是因为同屏可见 deploy-94 / accept-95 两行；凭空概括即属编造证据。
- **原生终端证据 vs 后期 UI**：标注层是独立后期浮层，必须加小号“说明”标记，不得排成仿终端原文。终端原文里的暖色（如黄色“🌙 via”提示符）是**原始录屏证据**，保留原样，既不改也不计入标注缺陷；后期 UI 一律冷青蓝/浅灰，禁止用金色去“统一”原生提示符——那等于篡改证据。
- **全时段图层生命周期回归（每个标注逐个过）**：任何后期标注都必须按 `出现 → 保持 → 退出` 三段抽检，每段至少各取一帧，并额外截取进入前 0.1s 与退出后 0.1s，确认“该出现时已出现、保持期位置/透明度不变、该消失时已完全消失”。只抽中间帧属于漏检：EP07 oldlog 的 5.9s 淡出中、6.3s 已消失就是靠边界帧才抓到。新增/修改标注时，同一回归要覆盖**全部**标注，不只改动的那个。
- **全时段金色扫描**：阈值 `R≥180, G≥120, B≤160, R≥G+15, G≥B+25`（通道先转 int16 再比较，防 uint8 溢出）；必须按**每套标注各自的空间子 ROI + 有效时段**统计，**不得用整幅终端 ROI 代三套**——原始终端自带暖色提示符，整幅扫描会把它误判为标注失败。剩余暖色可用**旧版成片同帧**（不是未剪辑原 MOV）的宽松暖色 mask（`R≥120, G≥90, B≤180, R≥G+3, G≥B+10`，±3px/7×7 邻域）解释来源，但该检查不替代子 ROI 的 0 结论。EP07 实例：oldlog `[220,860)×[618,672)` 0–6.2s、focus `[0,1080)×[608,668)` 6.2–10.2s、pending `[240,840)×[1235,1295)` 10.28–16.37s，三套均为 0、单帧最大 0，源暖色未匹配 0。
- **表述纪律**：结论写“三套后期标注层无金边金字”，不得写成“整幅终端原片零金色”。
- **单层原则**：同一说明只保留一个载体（PNG 或 ASS）；改用 ASS 烧录时必须删除旧 PNG 里的文字，防双层。
- **复核标准**：独立 reviewer 需做全片解码、**全片实际 N 帧全量扫描**（N 以 `ffprobe -count_frames` 实测为准，新片帧数可能不同，不得沿用上一集数字；EP07 实例 N=735）、双指纹比对与关键帧目检；证据连同口径说明归档到当集 `剪辑/审核证据-vXXX/`，不只留在 /tmp。

## 9. 运动预算与叙事门槛（EP08 起，EP07 复盘后新增）

EP07 的教训：五轮返工（v003–v007）全部在画面合规层，正片结构从未被审视，最终得到一条“技术无可挑剔、但没有人看完”的片子。以下三条为硬门槛。

- **三层运动分开记，不得互相替代**：①源素材运动（原始录屏/实拍里真实发生的变化）；②取景运动（crop / zoom / 横摇 / setpts 慢放）；③标注与字幕事件（浮层出现、消失、强调）。某一层的 YDIF 高，不代表另两层有运动；判断“画面是否在动”必须说明是哪一层。
- **运动预算**：渲染前在分镜表标出每个 3 秒窗口的视觉事件。连续静止不得超过 3 秒；超过则必须有信息更新（画面内容变化、字幕强调、UI 动效任一项），否则返工。
- **正向节奏阈值**：节奏抽检用 YDIF 与画面变化量，低于约定阈值即返工；**不以“YDIF ≠ 0”作为通过标准**（EP07 的静止板子能过旧标准）。
- **叙事验收（人判，不可由技术项推导）**：前 3 秒必须给陌生人一个可看之物，优先真实执行结果；标题承诺在正片内兑现或明确指向下一集；结尾要有“值了”的落点。禁止为画面虚构未发生的动作（例如把设备上的 Open 键剪成“AI 正在执行”）。
- **返工停止线**：外观类返工连续两轮未见留存改善，强制转向结构修改（时长、顺序、信息密度），不再继续修像素。
- **发布前独立勾选**：叙事验收是 `04-发布执行与复盘/发布前核验清单.md` 的第五项，技术验收通过不代表它通过。
