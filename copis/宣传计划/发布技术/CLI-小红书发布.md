# CLI-小红书发布（copis-chrome）

> 2026-10-21 用 copis-chrome v0.1.11 首次走通小红书创作服务平台视频笔记流程：切标签页 → 上传 MP4 → 标题/正文 → 封面上传 → PK封面 → 暂存离开（草稿箱确认 +1）。
> 2026-10-22 用 v0.2.2 完成 EP07 闭环（地点+定时发布 20:48）。v0.2.2 变化：`connect` 必须带 `--window <windowId>`；daemon 重启正确姿势 = `daemon stop`（优雅停，不触发 Copis.app 自动重生）→ `daemon run` 后台 → `windows` 查 windowId → `connect --window <id>`。
> 通用底座（daemon/连接/坐标方法论/输入规范）见《CLI-视频号发布.md》第一、二章，本文不重复。

## 一、环境与前置

- 创作服务平台与视频号助手常在同一 Chrome 窗口的两个标签页；`observe` 的 OCR 里 (449,21) 处「小红书创作服务平台」即标签页，**点击标签页即可切换**（切换后 frameId 会变，须重新 observe）
- 发布页 URL：`https://creator.xiaohongshu.com/publish/publish?from=menu&target=video`（target=video 为上传视频页签）
- 登录态：右上角显示「织界-LoomOS」即已登录
- 首次上传会弹**浏览器原生位置权限弹窗**：CLI click 报 `POINTER_OBSCURED`（原生层不归页面），用 CGEventPost 兜底：activate Chrome 后 click 屏幕 (469,315) 命中「一律不允许」（screen = 窗口原点 (189,30) + frame (280,285)）。**建议点「一律不允许」一劳永逸**，之后地址栏显示 🚫 不再弹

1. **切标签页**：点 (449,21)，observe 确认 URL 变为 creator.xiaohongshu.com
2. **上传视频**：点上传区 (710,689) → `select-file` → `"dialogClosed":true,"selected":true`；约 8s 后表单出现（描述计数器 0/1000）
3. **关权限弹窗**（仅首次）：CGEventPost 点「一律不允许」，见第一章
4. **向上滚**：上传后页面停在中部，`scroll --delta-y -500`（负值=向上滚）露出封面区+标题框
5. **标题**：点标题框 → `type`（≤20 字，如「织界 EP06：我先摸个底」11 字）
6. **正文**：点正文框 → 逐段 `type` + `press Enter`（与视频号同法）；末行输话题。**话题直输 `#xxx` 只是纯文本**，会弹联想下拉（`Escape` 可关）；真话题（绿色可点击）需在下拉中逐个点选——批量发布建议接受纯文本或逐个点选
7. **封面**：点封面缩略图 → hover 浮现「编辑封面」→ 点它进全屏编辑器（左工具栏：裁剪/贴纸/文字/滤镜）→ 点「+ 上传」→ `select-file` 封面 png → 点「完成」→ 表单缩略图更新并显示「封面效果评估通过」；缩略图带「主封」角标
8. **PK封面**（可选，**注意点的是 toggle 不是文字**）：toggle 在「设置封面」标题行最右侧 (890,368)，点开后出现「PK封面 0/3 智能推荐」槽位区（主封面 + 3 个智能推荐格子）；72 小时后点击率最高者自动成为主封面。⚠️ **开关开着但 0/3 无候选图时会拦截发布**（报错「请至少添加一张 PK 封面」）——没准备好 PK 图就先关掉开关再发
9. **加入合集**：点「加入合集」(345,509) → 下拉出现已有合集（如「织界LoomOS」(690,558)）→ 点选 → 行右侧回显合集名
10. **原创声明**：点 toggle (543,587) 展开面板 → 类型卡片默认已选「视频」→ 勾选「我已阅读并同意《原创声明须知》」勾选框 (280,841) → 「声明原创」按钮 (908,840) 由灰变红后点击 → 面板收起、toggle 保持红色开启
11. **添加地点**：⚠️ **点「添加地点」行本身获得焦点后直接 `type`**（EP07 实测纠正：不必展开下方搜索框再输入，展开的搜索框里 type 反而经常不落）；EP07 坐标：行 (328,1047) → type「融侨江南水都名筑」→ 行上方弹出联想结果「江南水都-名筑31座／闽江大道197号」(344,974) → 点选 → 行首回显「◎ 江南水都·名筑31座」
12. **定时发布**：滚到底「更多设置」区（默认展开）→ 点「定时发布」toggle（EP07 (543,1164)）→ 时间字段预填「当前+1h」→ **时间取值必须按该集 `发布文案.md` 的发布建议时段**（EP07 建议 20:30–21:00）→ 不在时段内则点时间字段弹时间面板：左侧为 10 月日历（默认今天不用动），右侧两列滚轮「时/分」——点小时列数字即选中（表头回显如「20时」），分钟列用 `scroll`（正值向数值增大方向）滚到目标后点选，行距约 37px → 弹层收起、时间字段回显（EP07 定为 2026-10-22 20:48）→ 底部按钮变「定时发布」(657,1266) → 点击 → 跳转 `publish/success` 页显示「发布成功」
13. **暂存离开**（存草稿）：(513,1266)，草稿箱「视频笔记（N）」+1。**视频草稿存浏览器本地**，清浏览器数据会丢

## 三、与视频号流程的差异

- 合集在「加入合集」行（点开下拉直接列已有合集，无弹层）；地点在「添加地点」行（搜索框内输入+点选 POI，交互类似视频号位置）；标注对应「原创声明」（toggle+类型+勾选须知）；定时在「更多设置」里（toggle 开关式，非单选，时间预填当前+1h）
- 小红书 toggle 开关都在行内**文字右侧约 +50px** 处，点文字本身不会生效；PK封面 toggle 误点展开说明的情况已实测（(840,163) 是错误坐标）
- 标题限 20 字（视频号短标题同格式可复用）；正文限 1000 字
- 话题必须经联想下拉点选才成为真话题（视频号可整行粘贴纯文本话题）
- 草稿在浏览器本地不在云端
- 上传页签：上传视频/上传图文/写长文/发播客；草稿箱入口在右上角
