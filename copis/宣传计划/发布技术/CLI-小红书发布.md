> 2026-10-23 EP08 wb003 改用 **mcc CLI v0.2.4** 全流程发布成功（立即发表）。mcc 与 copis-chrome 命令面同源，差异要点见《CLI-视频号发布.md》头部 mcc 段（≤1600px 截图上限 / daemon stop 收尾 / 弹窗 observe 滞后等）。本次新增实测经验：
> - **正文 type 不接受换行符**（报 INVALID_ARGUMENT「不能包含控制字符」）——换行必须用 `press Enter`，与视频号同
> - **话题逐个下拉点选实操**（EP08 首次全量走通 9 个真话题）：正文末尾 `type " #关键词"` → 联想下拉第一项通常即精确匹配（右侧带浏览数）→ observe 后点选 → 话题变绿 → 接着输下一个。下拉项坐标每次都变，必须逐次 observe；吃不准时 `screencapture` 裁剪核对
> - 点正文任意处会移动光标——话题必须等正文全部输完、光标停在末尾时再输；中途插错按「清空重打」最稳（EP08 实操：Cmd+A + Backspace 清空后重打一次成功，标题不受影响）
> - **封面编辑器新版为内嵌面板**（非旧版全屏弹窗）：点缩略图 hover 出「编辑封面」→ 进编辑器 → 「+ 上传」select-file → 封面直接生效，右侧手机预览实时更新；「完成」按钮在编辑器右下（EP08 窗口 1256 宽时在 (1168,762)），**窗口太窄时该按钮可能被挤出视口**——发布前确认封面回显「封面效果评估通过」
> - 原创声明 toggle：行内文字右侧较远处（EP08 (563,1141)），先 `screencapture` 截行定位再点；面板展开后勾须知框 → 「声明原创」变红点击 → 面板收起 toggle 保持红色
> - 添加地点：EP08 复核 EP07 结论——点「添加地点」行获得焦点后直接 `type` 全称，联想列表在行上方弹出，点选后行首回显（本次「江南水都·名筑31座」一次命中）

## 三、与视频号流程的差异

- 合集在「加入合集」行（点开下拉直接列已有合集，无弹层）；地点在「添加地点」行（搜索框内输入+点选 POI，交互类似视频号位置）；标注对应「原创声明」（toggle+类型+勾选须知）；定时在「更多设置」里（toggle 开关式，非单选，时间预填当前+1h）
- 小红书 toggle 开关都在行内**文字右侧约 +50px** 处，点文字本身不会生效；PK封面 toggle 误点展开说明的情况已实测（(840,163) 是错误坐标）
- 标题限 20 字（视频号短标题同格式可复用）；正文限 1000 字
- 话题必须经联想下拉点选才成为真话题（视频号可整行粘贴纯文本话题）
- 草稿在浏览器本地不在云端
- 上传页签：上传视频/上传图文/写长文/发播客；草稿箱入口在右上角
