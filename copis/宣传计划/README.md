## 以后怎么放

- 一篇笔记一个目录：`README.md` 放状态与制作要求，`publish.txt` 只放标题、正文和话题，画面脚本另放。
- 新图片放对应笔记的 `images/`，用 `01-封面.png`、`02-内容.png` 命名；没有图片时不创建空素材来冒充成品。
- 新视频的最终 MP4、字幕和工程分开放；可运行代码及依赖写入 `project/`，不要把 `node_modules` 混进宣传交付目录。
- 修改版追加明确版本名和更新原因，不用“新”“最终最终”等模糊名称覆盖历史。
- 现有 `.env`、cookies、登录二维码和 `.workbuddy` 不复制进本工作台；仅凭公开素材文件名和内容做索引。
- 来源目录的旧 README 有失效的 `notes/` 等链接和过时状态，本工作台使用实际存在的资产路径，不继续沿用它们。
- 本轮仅完成文字及制作脚本。尚无新生成图片、配音、视频，也没有执行发布或改动自动任务。
