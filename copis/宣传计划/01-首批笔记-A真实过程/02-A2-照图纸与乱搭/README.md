# A2｜不照图纸，也不等于随便搭

状态：文字完成；配图未生成；未发布。

- 读者：孩子喜欢搭积木，家长想尝试开放任务，但不知道怎样开始。
- 目标：提供一个任务表达方法，不比较孩子或搭建方式的优劣。
- 形式：五页图文；课程设计示意，不声称已有对照实验。
- 标题：不照图纸搭小车，先说清楚要做什么
- 备选标题：孩子想自己搭，先约定怎么才算完成
- 封面主文案：不照图纸／先说清要做什么
- 封面小字：让开放任务有一个可以测试的目标
- 文件：[复制文案](publish.txt)、[逐页稿](图文逐页稿.md)。

## 事实和制作约束

不再使用“照图纸的娃输给乱搭的娃”“自由搭建跑得更直”等没有实测支持的说法。图纸可以是起点，本篇讨论的只是另一个可选任务方式。图中左右对照是任务说明方式的差异，不是两个孩子能力的对照。
