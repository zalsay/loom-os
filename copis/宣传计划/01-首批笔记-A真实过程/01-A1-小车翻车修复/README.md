# A1｜小车走偏时，先别替孩子修

状态：文字完成；视频未生成；未发布。

- 读者：看见孩子作品出问题，就想马上帮忙解决的家长。
- 目标：把“帮孩子解决”转成“帮助孩子观察”，引导读者收藏或交流自己的处理方式。
- 形式：课程设计说明视频；不是课堂实录。原计划中的“跑偏三次、我被拦下”留待真实素材验证。
- 标题：小车一跑就偏，先别急着替孩子修
- 备选标题：孩子搭的小车走偏，先问他看到了什么
- 封面主文案：小车走偏了／先别替他修
- 封面小字：从“帮忙修好”到“帮忙观察”
- 画面：左侧一条弯曲轨迹，右侧放大车轮与底盘；不做虚假的修复成功对比。
- 文件：[复制文案](publish.txt)、[视频分镜](视频分镜.md)。

## 事实和制作约束

可讲课程设计里的观察、预测、测试与修改；不可讲“今天的课堂上”“孩子拦住我”等未证实事件。片头、视频主要画面与发布正文明确课程设计示意。涉及电机的演示须由老师按现场安全要求检查，不提供接线教学。
