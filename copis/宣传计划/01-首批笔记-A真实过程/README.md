## 使用方法

各篇 `publish.txt` 是可复制的正文；`README.md` 是内部 brief，不要整段复制发布。`图文逐页稿.md` 和 `视频分镜.md` 是制作稿，不代表已有新图片或新视频。

统一使用深色纸纹、暖白/暖金、青蓝笔触和织界 Logo。示意内容显式标注；不在图中伪造真实儿童照片、手稿或测试数值。发布前依照 [核验清单](../04-发布执行与复盘/发布前核验清单.md) 检查。
