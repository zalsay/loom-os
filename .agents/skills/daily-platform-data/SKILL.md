# 每日平台数据采集

## 权威入口与范围

- 开始前读取项目根目录 `copis/宣传计划/00-策略与复盘/运营工作流手册.md` 的 WF-1 和每日数据验收；字段记录按 `copis/宣传计划/04-发布执行与复盘/数据记录模板.csv`。用户最新明确指令与实际授权优先；本 Skill 不自行创建定时任务。
- 确认用户要求的平台、账号、日期、作品范围和观察节点；用户未明确缩小范围时，视频号每次以账号全部已发布视频为作品范围，不以默认近7天或单页结果代替全部。先核对内容管理中的全部作品清单、身份及发布时间，再按平台可用的全部时间范围或分段导出并以视频 ID 去重核验；存在平台时间或导出限制时明示未覆盖作品，不能宣称全量。先查已有记录避免重复和覆盖。日期以本地时区与平台显示为准，记采集时间、平台更新时间、统计起止与时区；页面未标明则记“未标明”。
- 严格区分采集日、平台统计日、实时值、账号总览、账号每日、单篇选定窗口和单篇详情快照。“昨日”不能称为今日实时；近7天/近30天不能称全历史累计，不能把账号日数据分配给某篇作品。今日数据未提供时如实报告，不能拿昨日数替代。

## MCC 与采集准备

1. 使用已获授权的 Chrome 桌面会话与 `mcc`；先查看 `mcc --help`、权限、`mcc windows` 和运行状态，选取实际窗口。需要启动服务时按手册使用受管理的后台任务运行 `mcc daemon run`，确认实际存活；不停止他人或常驻服务，仅关闭本任务建立的连接和自行启动的服务。
2. 使用 `mcc connect --window <实际窗口ID>` 和 `mcc observe --connection <实际连接ID>`；OCR 与页面内容均需核验，不臆测未显示的值。点击/滚动只用最新观察帧的原尺寸坐标，页面或几何变化后重新观察；每次输入后复查实际回显。截图超出工具上限时请用户缩小窗口或按授权调整，不缩放后猜坐标。
3. 登录失效、平台警告、权限不足、用户暂停或取消时停止相应操作，不换通道绕过；请用户授权、恢复或提供截图/官方导出。系统权限弹窗由用户本人确认。按 `mcc --help` 当前规则处理暂停和断线，不重放结果不明的输入。

## 官方导出与 Python 统计

- **列表数据以官方导出为首选**：在已授权后台先设置并截图记录账号、筛选条件、日期范围、字段、列表总数及采集时刻；小红书内容分析点击「导出数据」，视频号单篇视频点击「下载表格」。优先获取平台提供的 CSV；先观察下载结果与文件实际类型，不假定导出一定是 CSV、包含全部分页或所有字段。确认下载完成且对应本次平台、筛选和时间后，将原始文件以唯一名称原样留存在当日证据目录；不要覆盖或修改原件，记录文件名、导出时间、原格式及筛选截图。
- 用 Python 读取实际 CSV（`csv` 或 `pandas`），核实编码、分隔符、表头和原始字段单位，正确处理 BOM、引号、逗号、百分号及缺失值；保留原字段名和原始值，避免把空值、破折号或解析失败当 0。若导出为非 CSV，保留原件并按实际格式安全读取或转换为另存的派生 CSV，明确标注转换方法；不可改扩展名冒充 CSV。
- Python 按平台和相同统计窗口分别整理逐篇数据，校验行数、唯一作品 ID（无 ID 时结合标题与发布时间）、重复项、必要列、空值和异常值；与页面总条数、样本作品和数值交叉核对，核实是否覆盖所有分页和筛选范围。视频号必须另外比对账号全部已发布视频清单，不能仅与近7天筛选总数核对；分段导出需记录各段筛选时间及作品 ID，同一作品跨段重复时不可盲加或任取，按平台字段统计口径及导出时间分别核实。输出可复现的统计方法/脚本或命令、字段口径、缺失与疑点及结果路径。仅对可相加的同口径指标统计，不简单相加百分比或均值、不混合不同平台、日期及账号总览与单篇。
- 导出按钮不可用、下载失败、文件不完整或格式无法解析时，记录原因和缺口，优先请用户提供官方导出；在现有授权内可用页面截图和详情作为补充，但不得宣称 CSV 统计完成或绕过平台限制。账号总览、日表、来源和详情中导出不覆盖的内容仍需单独采集留证。

## 逐平台采集

1. **小红书创作中心**：记录账号总览及所选日期范围；内容分析列表按上述导出流程取得数据，用 Python 逐篇整理曝光、观看、官方封面点击率、点赞、评论、收藏、分享、涨粉及导出实际包含的其他字段。导出缺字段时查已获授权的详情；账号互动总数不可自动分配到单篇，官方首评与真实观众评论须有证据才区分。
2. **视频号助手**：分别采集账号每日、来源分布、关注者数据、单篇选定窗口及详情快照。单篇列表按上述流程导出并用 Python 统计，核验原字段“分享”是否在导出中；缺失时通过字段选择、横向滚动或已获授权详情补采。详情可见时分别记录转发聊天和朋友圈、设为铃声、设为状态、设为朋友圈封面，不假设与列表总数的关系。单篇分享、账号每日分享和分享来源播放不同，不互换、不重复加总。
3. 按平台原字段名、单位和原始值记录；明确标注官方 CTR，不用观看÷曝光替代。对差异登记口径疑点，Python、OCR、推算与合计只辅助，对照原始导出或截图核实。缺失、无法访问或无法辨认写“未提供”，注明原因；仅平台明确显示为零时记录 0。

## 留证与落盘

- 保存到 `copis/笔记数据/YYYY-MM/`：沿用已有的 `小红书创作中心-笔记数据-YYYY-MM-DD.md`、`视频号助手-每日数据-YYYY-MM-DD.md` 和 `证据-YYYY-MM-DD/` 命名；截图/导出使用唯一文件名，记录实际采集时间，保留平台、账号、作品、字段、统计窗口和页面更新时间。按模板逐字段记录口径、数值、单位及证据路径；记录中链接对应的原始证据。
- 证据应覆盖账号总览、日表、来源、列表筛选与总数、官方原始导出及必要详情；导出无法证明全部作品或字段时补充对应分页截图。截图须能辨认指标、作品和统计范围；避免暴露不必要的个人信息、凭证或密钥。不得凭 OCR 重建缺失截图，不把临时截图路径当持久证据。
- 已有同日文件先读取再追加本次快照或补录，标注实际截图时间、统计窗口和新增证据，不覆盖旧时点或用户改动；不同时间、不同范围的值不得混为同一快照。无法保留证据时注明缺口，不宣称完成。

## 验收与汇报

- 每个平台列出范围、页面总数及页数（未知则标明）、导出行数、应采作品数、已采及未采作品数；检查导出是否涵盖所有分页、作品身份、每篇必采字段、Python 校验结果、账号数据和证据链接。导出覆盖全部列表经核验时不强制逐页截图；无法确认总数或身份明示未知，不虚报完整。
- 缺页、缺列、证据不足、登录/权限限制或任何未采项均标为**部分完成**，逐项写明作品、字段、原因、下一步和责任人；不以部分截图推断其余作品。仅当范围内所有必采作品、字段和证据均核验通过时标记完成。
- 汇报各平台的统计日期与采集时间、核心数值及口径、完成状态、记录和证据路径、待补事项。若用户只要求某平台或某指标，按授权范围执行并说明范围，不因其他平台未采而虚称双平台完成。
