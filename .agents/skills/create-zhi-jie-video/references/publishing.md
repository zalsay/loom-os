# 发布文案与封面规范

沉淀自 2026-10-16 EP01/EP02 发布执行（用户逐轮定稿）。每集视频做完后，发布文案与封面按本文执行；成品统一写入各集 `产物/` 目录（成片 mp4 + `封面-EPXX.png` + `发布文案.md`），过程版本与剪辑记录留在 `剪辑/`（2026-10-19 EP03 起定此结构）。

## 视频标题（平台硬限制）

- **固定格式**：`织界 EPXX：正文`，全题 **≤16 字**。前缀「织界 EPXX：」占 8 字，正文最多 8 字，正文要表达完整意思（如"能提问的板子到了""第一次通电全记录"）。
- **符号白名单**（小红书标题校验，超出即被拒）：书名号《》、引号、冒号：、加号 +、问号？、百分号 %、摄氏度 ℃；逗号用空格代替。**禁用** ·、｜、！、——、emoji 等。
- 迭代记录：`织界创造日记 EPXX｜正文`（超字数）→ `织界·EPXX｜正文`（· 与 ｜ 不是合法符号）→ 定稿 `织界 EPXX：正文`。新集直接用定稿格式。
- **口吻检查（v012 定稿，EP03 补充全文规则）**：叙述者是 AI（第一人称「我」），标题禁「AI 做了 X」式表述 → 改 AI 自述（「AI给板子做体检」被否 →「我给板子摸个底」）。**屏幕大标题、封面标题、发布文案标题三处必须同口吻**，改一处要同步另两处。**发布文案全文（简介、看点、置顶评论）同此口吻**：AI 自称「我」、人类方称「人」（如「我负责干活，人负责把关」）——EP03 初稿「给 Mosaico 做体检的不是我，是 AI」把「我」让给了人类，被否；定稿「我没急着动手，先把它从里到外摸了一遍」。

## 发布文案（各集 `发布文案.md`）

每集发布前写好并落盘，结构固定五段：

1. **视频标题**：推荐 1 条 + 备选 2-3 条，全部 ≤16 字、过符号白名单。
2. **视频简介（直接复制）**：从观众熟悉的问题切入；列本集画面可见的 3-4 个看点（用 · 列表）；片尾钩子指向下一集；结尾固定一句账号背景「织界是一个 AI 教育项目，账号内容从策划、拍摄剪辑到文案，都由 AI 主导完成，人类伙伴负责把关」。
3. **话题**：直接**沿用上一集话题行复制**，只把本集事件词换成当集标签（EP02 #第一次通电 → EP03 #开发纪实），不自行增删领域词；编辑器内逐个输入确认成 `#xxx[话题]#` 格式。（EP01/EP02 行：`#织界 #LoomOS #Mosaico #乐鑫 #AI教育 #<本集事件词> #STEAM教育 #儿童编程 #硬件测评 #创造日记`；EP03 曾自行改成 12 个被否，用户定稿「复制之前的」）
4. **发布建议**：封面文件指向本集 `产物/封面-EPXX.png`；发布时间 19:00-21:00 家长活跃时段，**EP03 起按数据复盘收敛到 20:30-21:00**（EP02 验证优效时段）；与上集间隔 2-3 天；置顶评论文案（引导评论 + 预告下集，同第一人称口吻）。
5. **事实边界**：只陈述画面可见/官方口径内容；不宣称联网成功、不提 Loom OS 已在真机运行（留给后续集数）；不说效果承诺类话术；涉及隐私的画面必须用打码版成片（如 EP02 必须用密码打码 v002）。

## 封面（1080×1440，3:4）

标题放大居中是用户定稿方向（视频内的顶部小标题不适合直接当封面）。定稿版式：

| 区域 | 参数 |
| --- | --- |
| 画布 | 1080×1440（3:4，小红书视频封面标准），背景 `#283840` |
| 弱水印底 | 织界 logo 940px，alpha 5%，标题区居中 |
| 徽章行 | 「──  织界创造日记 · EPXX  ──」金色 42px（W3），y≈92 |
| 金色细分隔线 | (440,168)-(640,168)，宽 3 |
| 主标题 | 白色 W6 96px，y≈210，文字阴影+高斯模糊 |
| 副标题 | 亮金 `#FAC864` W6 140px，y≈360 |
| 实拍画面 | 1080×810 置于 y=630-1440，亮度 ×1.08、对比 ×1.05（封面稍提亮） |
| 画面底部 | 渐变压暗（y560 起至 150/810）+ 织界 logo 300px 92% 透明度，距底 40px |

执行要点：

- **帧选取**：从剪辑基底（无烧录字幕版）抽帧，`crop=1080:810:0:0`（竖版基底）或 `crop=1440:1080:240:0` → `scale=1080:810`（横版源）。先做小图 contact sheet 扫候选，选**产品清晰、构图不挤、无大面积暗部/手部遮挡**的帧；EP01 定稿 36s（设备+橙轮），EP02 定稿 146s（屏幕点亮连 WiFi 界面，无密码，无隐私问题）。
- **隐私**：封面帧同样过一遍敏感信息检查（密码/地址/人名），打码版成片里的帧已处理，源素材帧需人工确认。
- **字体**：Hiragino Sans GB（`/System/Library/Fonts/Hiragino Sans GB.ttc`），W6 粗体 = index 2；PingFang 受 SIP 保护 PIL 不可直读。
- **配方脚本**：`scripts/make_cover.py`（参数：--frame/--badge/--line1/--line2/--out），与视频同色系（#283840/#FAC864），勿另起风格。

## 交付前检查

1. 标题 ≤16 字且只含白名单符号（逐字符过一遍）。
2. 简介无越线表述（对照各集事实边界 + `00-策略与复盘/事实依据与素材边界.md`）。
3. 封面帧无敏感信息、产品清晰；标题两行居中不与水印冲突。
4. `产物/` 内 `发布文案.md`、`封面-EPXX.png` 与成片版本（打码版等）对应正确；话题含系列固定 8 个；全文口吻为 AI 第一人称。
