# 竖版小红书实拍版规范

沉淀自 2026-10-16 EP01 开箱竖版 v001→v010 十版迭代（用户逐版反馈定稿）。把横版实拍素材转成 9:16 小红书视频、或给实拍竖版加品牌包装时，先读本文。

## 画布结构（1080×1920）

| 区域 | 参数 | 说明 |
| --- | --- | --- |
| 整体背景 | `#283840`（片尾卡实测主色） | pad 色，勿用纯黑 |
| 实拍区 | 4:3 中心裁切：`crop=1440:1080:240:0` → `scale=1080:810`，pad y=440 | 4:3 比 16:9 裁切高度 +33%，用户定稿 |
| 顶部标题区 | y=150 系列徽标（40px 金）、y=235 两行钩子标题：第一行白 74px + 第二行亮金 92px | 悬念钩子式两行标题为用户定稿 |
| 字幕 | 66px，y=1310 | 比宣传片的 54px 大，手机端可读优先 |
| 底部装饰区 | y≈1250-1920 | 见下方装饰层配方 |

## 底部装饰层（v010 定稿）

底部不要留纯色空底。用 PIL 预合成整幅 RGBA 装饰层，ffmpeg 单次 `overlay=0:0` 置于字幕之下：

- **主 logo**：300px 宽，中心 (540, 1620)，完全不透明，居中于底部区中部。
- **大水印**：980px 宽，中心 (540, 1670)（与主 logo 错位 50px 有层次），**alpha 5%** 起步，作半透明弱背景。
- 层序：背景 → 水印 → 主 logo → 字幕（字幕必须在装饰层之上）。
- 水印存在感以「隐约可见、不抢字幕」为准，用户反馈强/弱只调 alpha 一个参数。

## 去烘焙文字（v009 定稿）

原素材常带烘焙章节字/水印字。两种工具的适用边界：

- **delogo**：适合纯色/低细节背景（如左上角系列徽标区 `x=2:y=6:w=480:h=62`）。文字压在产品印刷、纹理等高细节背景上时**禁用**——会把整块区域涂花。
- **removelogo 笔画掩膜**（定稿方案）：只抹文字笔画、保留底下印刷。配方：
  1. 取文字完整可见的一帧（如 2.0s）；
  2. 在文字 bbox 内按亮度阈值（>195，高于底下印刷实测峰值 ~117）提取笔画，膨胀 2px 吃掉抗锯齿边，生成 1920×1080 掩膜 PNG；
  3. `removelogo=mask.png`。掩膜必须**限时作用**（文字淡出时刻为止）：`split` → `removelogo,trim=0:T` / `trim=start=T` → `concat`，否则掩膜区在后续画面被持续涂抹。
  4. 印刷与笔画重叠处会有轻度残痕，动态画面中不明显，可接受；交付前抽帧确认。

## 首帧非黑屏（v009 定稿）

竖版首帧即小红书封面，禁止黑屏/淡入起手：

- **渲染链禁止 `fade=t=in:st=0:...`**（EP03 开发纪实 v001 踩坑：0.3s 淡入使首帧亮度仅 31，近黑）；成片后必须测首帧亮度（0.1s 抽帧灰度均值，应与画面正常亮度一致，EP02 v002 修复后 61.5）。
- 先测开头亮度曲线（scale=64:36 灰度逐帧均值）确认黑场时长（EP01 实测仅 0-0.2s，lum 11→68）。
- 取黑场结束后首个稳定帧，做同样清理（去字+去徽标）后存 PNG，`-loop 1 -t 黑场时长+0.05` 作输入，`overlay=0:0:enable='lt(t,T)':eof_action=pass` 冻结铺满开头，T 处与实拍帧无缝衔接。
- 时间轴零位移：冻结只补画面，不改任何旁白/字幕时间。

## 配音：整篇合成再切片（v007 定稿，音色一致性硬规则）

逐段调用 voiceclone 会有段间音色/语速漂移（用户实测反馈）。**全文一次合成，再切到分镜**：

1. 各分镜文案拼接为整篇，单次调用。**语速定标：4.4-5 字/秒（用户定稿，3.6 太慢 / 6.6 太快）**，指令写法与「目标秒数非线性、一档摇两次取稳定值」硬规则见 [MiMo配音-语速定标](references/mimo-tts.md)；目标秒数 = 字数 ÷ 4.4。
2. 切点定位：`silencedetect` 扫句间停顿（干净样本 -33dB/0.16s；底噪高的样本先带通滤波 highpass 200 + lowpass 3800 再 -27dB/0.10s），与「按字数推算的句边界」交叉确认，取句后长停顿中点；用 `-c copy` 无损切片。
3. 切片时长必须全部落入对应分镜窗口（窗口 = 分镜边界 − 留白），放不下先精简文案重生成，勿硬塞。
4. 摆放：各段起点 = 分镜起点 + 0.2~0.6s 留白；切片自带句间停顿，段间自然留白即可。
5. 响度基准：旁白 1.0、现场声 0.18、BGM 0.32，`amix normalize=0`；BGM 片尾 2s 淡出。

## 字幕对位（v006/v007 定稿）

- **换旁白文案必须同步重生成字幕**——旧 ASS 与新语音必然错位（v005 踩坑）。
- 以切片后实测语音为准：段窗口 = 摆放起点 + 实测切片时长；段内逐句边界取静音图谱实测停顿，比按字数比例分配更准。
- 相邻句字幕首尾相接（连续无闪断），段间允许留空；金词高亮 `{\c&H64C8FA&}` 随所在句显示。

## 轻快 BGM（v008 定稿）

- 慢和弦铺底被用户否决（「太平淡」），实拍过程片用轻快风：C 大调 120BPM、马林巴拨弦反拍切分 + 轻低音 + 五声音阶旋律点缀 + 沙锤。
- 新旧 BGM 必须同响度对齐后再进混音（8k mono s16 RMS 口径对齐，EP01 案例 418 vs 420），混音比例不变。
- numpy 合成配方存 EP01 剪辑目录说明；换调性/速度即可复用于后续 EP。

## 关键帧动效（v010 定稿，Remotion 语义）

- 用户明确否决「zoom 跑满整段」的线性 Ken Burns（观感成持续漂移）。关键帧动效 = 每段起点为关键帧，**0.8s 内 ease-out 快速放大到位后 clamp 停住**，等价 Remotion `interpolate(in,[0,24],[1,1.0X],{easing:Easing.out(Easing.cubic),clamp})`。
- ffmpeg zoompan 实现：`z='1+X*(1-pow(1-min(in/24\,1)\,3))'`（easeOutCubic = 1-(1-t)^3；表达式逗号需 `\,` 转义）。上限：画面区 1.08、终端文字区 1.05（保可读）。
- 画质保护：先 scale 到 2160 宽超采样、zoompan 缩回输出尺寸。
- 验证：抽帧像素差异——动效进行段差异应大（>10）、保持段差异应小（<2），可量化确认「到位后不漂移」。

## 素材硬规则：必须全视频（v004/v005 教训）

- 用户两次否决静帧轮播：**上下两路素材都必须是视频**。设备特写用 TP 相机录像，终端用 Otty 录屏。
- 录屏选窗前先量化运动量：`fps=1,signalstats,metadata=print:key=lavfi.signalstats.YDIF` 逐秒 YDIF，**YDIF=0.00 的窗口视觉等同图片，必须避开**；优先选命令输出滚动段。
- TP 相机录像候选先做 contact sheet 扫描：有人员/杂物入镜、夜间黑白夜视画质差的直接弃用。

## TP 相机画面裁切（EP02 定稿）

- TP 单帧/录像构图 = 左房间右设备，**必须裁掉左侧房间背景**（沙发/木柜/纸巾/时间戳 OSD），裁切参数按素材构图单独定标、**不可混用**：静帧 dev-frame-s2（设备偏右）= `crop=850:478:390:120`；录像 lua-verify-20（设备偏左）= `crop=900:506:80:100`。
- 定标方法：抽帧出 3-4 档候选裁切拼图对比，取「左侧最干净且设备不切边」档。

## 相机（FaceTime/新 Mac 相机）画面裁切（EP06 v003 定稿）

- QuickTime 相机预览窗口录出来的帧带黑边（EP06 session80：1392×832 里内容区只有 x 57–1332 / y 36–765）。**先裁掉黑边再谈构图**，否则上下黑边会顶掉标题与字幕空间。
- EP06 定稿参数：`crop=1275:718:57:52` → 1080×608（设备占满画面、背景最少，对齐用户给的参考帧）。**裁剪宽高必须严格等于输出面板的宽高比**（1080:608 = 16:9），否则后续 zoompan/scale 会把画面拉扁——先算高度 = 宽度 ÷ 目标比例，再去调 y 避开窗口边框。
- 换过摄像头（机型/机位变了）时先确认素材出自哪个 session：`ls -t 执行记录/` + 打开首中末帧 JPEG 看一眼，暗光旧机位与白天新机位是完全不同的裁切基准，参数不可套用。
- 明亮素材不需要 gamma 提亮（EP06 旧暗光素材提亮后发灰、噪点炸开，直接弃用换新相机素材）。

## 亮画面上的标题层级（EP06 v003）

- 标题压在实拍画面上时必须加**上暗下透的渐变遮罩**：380px 高、alpha 205→0（`(1-t)^1.35` 曲线），叠在相机层之上、终端层之下。没有遮罩时亮画面把白字与金字吃掉。
- 遮罩做成 PNG 一次性生成，`-i title-scrim.png` 走 overlay，别用 drawtext 反复调。

## 终端聚焦裁切（定格三幕版，EP06 v003）

- 定格终端（一次任务跑完、屏幕内容不再变化）不需要 zoompan 循环，**直接每幕一个 crop + scale 到面板尺寸**更快更稳；三幕用不同裁切框做「情绪递进」。
- 裁切框定标三条硬约束：①**宽度必须容下要强调的那一行全文**（EP06 的 `HOST_VALIDATION_PASS; DEVICE_RUNTIME_NOT_VERIFIED` 用 440 宽会把 VERIFIED 切掉，520 才整句可见）②**起始 y 必须避开不该出现的行**（EP06 终端里 `TimeoutError/SESSION failed` 是负向测试预期输出，y<545 就会带进来）③**底部不要把 Otty 状态栏/窗口黑边带进来**。
- 无法完全避开的内容（例如负向测试的红字 unavoidable）用 ASS `Note` 样式在片内加一行注解说明它是什么，别默认观众能自己判断——这类「看起来像失败的成功」是实机纪录最容易翻车的事实边界。

## 终端聚焦动效（v014 定稿）

- 用户定稿：聚焦**不能全程恒定**——每段命令行要有节奏：开始正常观看 → 中途聚焦左下角命令行起点 → 段尾释放，循环往复。
- 实现 = zoompan 分段循环 + 动态蒙层两层同步：
  - **致命陷阱：zoompan 的 `fps` 参数默认 25**——zoompan 输出流帧率元数据固定 25fps，下游 xfade 会按 25fps 时间基重新计时，而 z 表达式基于帧号 `in`，两者脱钩：聚焦进入延后 20%、缩回段被推入 xfade 过渡区永远看不到（症状=「释放时没回到原始大小」）。**所有 zoompan 必须显式 `:fps=30`**（与素材帧率一致），最小复现法：单链渲染数帧数（应收 N×30，若得 N×25 即中招）。
  - zoom 分段表达式（zoompan if 嵌套，fps=30）：`in<120` 全画幅 1.0 → 120-144 帧 ease-out 推进 **1.30** → 保持 → `N-69` 起 24 帧 ease-in 缩回 1.0。锚定 `x='0':y='ih-ih/zoom-off'`。**off 抵消源帧底部窗口黑边**（实测内容底：live-02 y984/高1058、live-03 y972/高1014，黑边 74/42px，按 scale 比例换算到超采样坐标 112/66）——否则聚焦视窗底边会包含黑边、悬在命令行中间。zoom=1 时 y=-off 被 clamp 到 0 仍全画幅。经验：1.15 聚焦感不足定稿 1.30；聚焦时机（fin）必须按素材命令执行节奏定标。
  - 蒙层动态化：每段一个 `-loop 1 -t seglen` PNG 输入，`fade=t=in:st=1.5:d=0.8:alpha=1` + `fade=t=out:st=fout_s:d=0.8:alpha=1`，与 zoom 时间点同步；**蒙层 overlay 放在 xfade 之前逐段合成**（避免 alpha 流过 xfade 的兼容问题）。
  - 蒙层浓度 alpha **170**≈67%（105 无聚焦感 → 215 用户说太暗 → 170 定稿），清晰带仅底部约 125px。
- 验证方法：`crop` 出蒙层区域用 signalstats YAVG 量化各时间点亮度，应呈「亮→暗→亮」循环；结尾段释放态收尾（字幕「关注织界」时画面全亮）。

## 终端「图片轮播感」修复（EP06 v012 教训）

- **症状**：终端三幕若全部取任务结束后的定格画面（-ss 90），哪怕加了 zoompan 推拉，用户仍感知为「图片轮播」——zoom 是镜头动，屏幕内容不动。**真实录屏运动才是视频感**。
- **先测运动量**：`ffmpeg -i src -vf "fps=1,signalstats,metadata=print:key=lavfi.signalstats.YDIF" -f null -`；YDIF 全程≈0 的段就是「视觉图片」。EP06 session80 实测整条 120s 录屏只有 t=1.6–3.4s 有真实打印（峰值 3.44），其余全静止。
- **setpts 慢放铺满**：真实运动太短时预渲染慢放段——`ffmpeg -ss <起> -t <长> -i src -vf "setpts=N*PTS" -r 30 -crf 16 live-stretch.mp4`（1.8s 打印 ×9.2 → 16.6s 逐行打印）。慢放后抽帧确认内容演进覆盖整段时长。act1/act2 都从 live-stretch 取，`-ss` 前后重叠 0.5s 保证 xfade 过渡区内容连续。
- **镜头跟随下摇**：打印内容向下增长时，act2 用 crop y 随时间缓动让「镜头」跟着滚到目标行：`crop=W:H:x:'D*(1-pow(1-min(max((n-A)/B\,0)\,1)\,2))'`（n=帧号，A=起步帧、B=时长帧数、D=总位移；用 n 不用 t，避免首帧 t=NAN）。运动幕**去掉蒙层**（固定暗带会压住正在打印的内容），只留定格幕的蒙层。
- **下摇必须与打印同步（EP06 v013 教训）**：v012 里 act2 取慢放段后段，下摇时打印已结束——用户反馈「聚焦期间 otty 没有输出」，镜头动了内容不动仍是图片感。**多幕共享一段真实运动时，按幕边界重新分配慢放映射**：每幕各自 setpts 预渲染（EP06 定稿 stretchA = 源 1.60–2.10s ×16.9 给 act1，stretchB = 源 2.10–3.40s ×8 给 act2），保证 ① 相邻幕首尾源时间连续（act1 末帧源 2.099 ≈ act2 首帧源 2.10，否则 xfade 处内容倒退/跳变）② 下摇区间内终端持续有新行打出。映射前先逐帧确认目标行（HOST 行）在慢放段时间轴上的出现时刻，让其落在镜头运动区间内。
- **xfade 混链陷阱（v012 踩坑）**：xfade 两侧一条走 zoompan、一条走纯 fps 链时，若 zoompan 漏了 `:fps=30`，两侧帧率元数据 25 vs 30 不一致，报 `Failed to configure output pad on Parsed_xfade_NN`（图级配置错误，不指明原因）。两侧都是 zoompan 链时双双 25fps 侥幸通过（v011），一混链就炸。**排查法**：最小双输入复现 + 链尾插 `showinfo` 看 `config in time_base / frame_rate`（实测 zoompan 漏配侧显示 1/25、25/1）。
- **成片验收**：对成片 otty 区域再跑一次 YDIF——应看到打印段（个位数）与下摇段（两位数）两组明显运动，不再全程 0。

## 音频硬规则（v005/v006 教训，强制）

- **成片采样率必须 44100 或 48000Hz**：voiceclone 原始 24kHz 不得直通输出（部分播放器/预览面板会静音）。
- 混音链固定：旁白 `adelay + volume≈1.15`、BGM `volume≈0.35 + 尾 2s 淡出`、`amix normalize=0` → `aformat=stereo` → `loudnorm=I=-14:TP=-1.5:LRA=11,aresample=44100`。
- amix 后**必须跑 volumedetect 查 max_volume**：峰值打到 0.0dB 即削波（部分播放器表现异常），用 loudnorm/limiter 压回 -1.5dB。
- **`amix` 多输入必须显式 `duration=longest`**（EP04 v001 踩坑：写成 `duration=first` 时整条混音被第一个输入截断——p1 旁白 9.2s 结束，10s 后含 BGM 全部无声，用户感知「12 秒后没声音」）。多段旁白 adelay 后进 amix，首输入不是最长时必然截尾；成片后必须加跑 `silencedetect=noise=-45dB:d=1.5` 确认全程无长静音。
- **loudnorm 单次通达不到 TP 目标**（EP05 实测：TP=-1.5 出样值峰值 -1.0dB）；补限幅用 `alimiter` 时**必须 `level=disabled`**——默认 `level=enabled` 会自动抬回满幅，限幅形同虚设（实测 -1.5 目标反变 -0.3dB）。定稿配方：`loudnorm=...:TP=-1.5,aresample=44100,alimiter=limit=0.80:level=disabled` → sample peak ≈ -1.7dB。
- 交付前音频验证三件套：声道数（立体声）、采样率、mean/max volume。
- **BGM 资产必须归档在项目目录，不放 /tmp**（EP06 v014 教训：`/tmp/ep1/bgm-upbeat2.wav` 与合成脚本被系统清理，EP04–EP06 的 BGM 一度无法复用）。重合成脚本已归档：`EP06-跑完却没交卷/剪辑/bgm_upbeat2_regen.py`（numpy 合成：A 大调 112BPM，持续和弦 pad（每和弦 8.57s、起振 0.3s 别太慢）+ 高八度琶音 8 分音符 + 低音根音，立体声 11ms 展宽，RMS 定标 720/32768 ≈ -33.2dBFS）。
- **BGM 响度校准基准 = 已发布成片实测**：EP05 成片纯 BGM 段 -37.4dB、片头 0.45s -40dB。新 BGM 合成后用「旁白+混音链的纯音频图」（不渲视频）量 intro/尾段，对齐该基准再渲片；pad 起振慢（≥1.2s）会让片头比基准低 10dB，intro 实测是校准敏感点。
- 混音公式：`[bgm]atrim=0:<片长>,volume=0.8,afade=t=out:st=<片长-2>:d=2` → 与旁白 `amix=inputs=2:duration=longest:normalize=0`。**volume 0.8 为用户定稿**（EP06 v015：0.4 时用户反馈「背景音乐音量太小」→ 提到 0.8/+6dB 后通过；旁白响度不受影响，BGM 约低于旁白 15dB）。历史版本 EP03–EP05 用过 0.32–0.4，新片一律 0.8 起。

## 交付前验证清单

1. 首帧非黑、烘焙字已除、产品印刷无大面积涂花。
2. 抽帧 ≥5 个点位（含每分镜中点 + 片尾）：字幕与语音进度一致、底部水印层次正确。
3. 语音包络：各段在位（RMS 显著高于纯 BGM 间隙），段间无串音；注意克隆语音句内有自然停顿，用连续包络勿单点采样。
4. 时长、封装（H.264/AAC、+faststart）核对；版本号递增且命名含特征（如「-轻快BGM版」），历史版本保留不覆盖。
5. 每版更新剪辑说明（本期目录 剪辑说明.md）：版本、改动、参数、验证结果，供下期复用。
6. 发布环节（标题/简介/话题/封面）按 [发布文案与封面规范](references/publishing.md) 执行，产出各集 `产物/发布文案.md` 与 `产物/封面-EPXX.png`（成品三件套统一放 `产物/`，过程版本留 `剪辑/`）。
7. 音频三件套：声道（立体声）、采样率（44100/48000，24kHz 禁直通）、volumedetect 查 max_volume 无削波（峰值 ≤ -1.5dB）。
8. 动效抽帧像素差异验证：关键帧动效到位后保持段差异 <2，确认不漂移；终端区蒙层上暗下亮分布正确。
9. 口吻一致性：旁白、屏幕大标题、封面标题、发布文案**全文**（标题+简介+看点+置顶评论）全为第一人称 AI 人话，无「AI 做了 X」式表述；话题复制上一集话题行、只换本集事件词。

## BGM 规则（EP06 v014–v016 教训沉淀）

- **BGM 原文件必须随项目归档**（各集 `剪辑/bgm-upbeat2.wav`），绝不放 /tmp——系统会清理，EP04–EP06 为此返工三轮。
- **禁止用「配方重合成」替代原文件**：各集 BGM 是每次独立合成的不同波形（EP04 与 EP05 成片同位置相关系数仅 0.07），重合成必然听感不对；丢了只能从历史成片反解。
- **从成片反解 BGM 的方法**（`recover_bgm.py`，EP06 已验证）：旁白分轨与成片相关性须 ≥0.99 才可用（EP05 分轨被重录覆盖、仅 0.72，不可用）；混音链线性部分用同款 ffmpeg 滤镜重建纯旁白轨，逐帧最小二乘估计 loudnorm 慢变增益（中值滤波 + 0.5s 平滑 + 两轮迭代把 BGM 计入参考），`b = (out − c·n)/(0.35·c)`，**只除一次 c**（多除会把增益呼吸印回 BGM）。质量验收：旁白区/干净区短时 RMS 比 ≤1.1、4–8kHz 齿音带残留远低于 BGM 本体。
- 混音公式：`[bgm]atrim=0:<片长>,volume=0.8,afade=t=out:st=<片长-2>:d=2` → 与旁白 `amix=inputs=N:duration=longest:normalize=0` + `loudnorm=I=-14:TP=-1.5:LRA=11,alimiter=limit=0.80`。volume 0.8 为定稿（历史 EP03–EP05 用 0.32–0.4 偏轻）。
- 校准敏感点：**片头 intro 是响度基准**（旁白未进、纯 BGM），换 BGM 源后先量 intro mean_volume 再渲片。
