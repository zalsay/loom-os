# 课程叙事与输入

## 项目背景

三至六年级，零基础起步。乐高兼容积木、孩子自己构建底盘，不依赖统一构建图纸。硬件背景：直流电机、L298N、两节18350电池模块、独立ESP32-S3控制端、Mosaico/Loom OS。当前代码功能、接线和部署状态依本期文档核实。

3m×4m开放教室，左侧3m边有入口，门外小花园为农场，每人一个放在地面且可移动的种植格。Linux服务器及教室数据设施的实际运行状态以当期记录为准，计划不等于已经实现。

## 本期输入

使用 `assets/templates/lesson-input.md` 记录日期/课次、孩子的问题、选择的方案、做过什么、发现、调整、尚未解决的问题、下一步和素材来源。真实引语要有来源，否则用叙述，不用引号冒充孩子原话。使用真实素材前核实用户允许的用途，未获授权的私人身份不要公开。

| 用途 | 主要内容 | 通常长度 |
| --- | --- | --- |
| 品牌宣传 | 想法进入设计、测试与作品的过程 | 45–60秒 |
| 课程周报 | 本次问题、一次尝试、一个变化、下一步 | 30–60秒 |
| 探索过程 | 多个方案、测试证据与修改 | 45–90秒 |
| 作品展示 | 孩子解释用途、测试、局限 | 30–60秒 |
| 阶段回顾 | 起点、关键修改、当前状态、接下来 | 60–90秒 |

每条短片聚焦一个问题。可以围绕小车走偏、轮轴摩擦、载荷或植物照顾，但只有记录支持才使用具体情节。数值必须来自实际证据；示意明确标注，不与真实成果混用。没有成功就讲发现，保留失败与不确定。

让孩子作主语，呈现“提问题 → 想办法 → 一起试”。使用固定AI表达，不写“AI帮我实现”或把孩子画成等待结果的人。按本期兴趣安排镜头，不强求每个孩子完成同样的成品。
