# 织界 Panda · 3D 造型室

独立的 Three.js 三维熊猫原型。以 `../LoomOS-panda-ink-clean.png` / SVG 为正面造型参考，重新建立有真实体积的头、身体、耳朵、四肢和尾巴；**不是 SVG 挤出，也不是正面图片贴在平面上**。

## 打开预览

需要 Node.js 20+ 和支持 WebGL 2 的现代浏览器。实际验证环境为 Node.js 24、独立 Chrome 测试实例。

```sh
cd /Volumes/RC500/dev/loom-os/logo/panda-3d
npm ci --registry=https://registry.npmjs.org
npm start
```

浏览器访问 `http://127.0.0.1:4178`。若该端口已使用：

```sh
PORT=4180 npm start
```

不要直接双击 `index.html`：本地 ES modules 与原画引用需要通过 HTTP 服务打开。服务仅绑定 loopback，不对局域网开放；不包含写入接口，也不提供仓库其他文件。

依赖通过 lockfile 固定，渲染不依赖 CDN、在线字体或远程贴图。安装依赖后预览可在断网状态使用。

## 操作

- 鼠标/单指拖动：环绕观察；滚轮/双指：缩放。
- 正面 / ¾ 视角 / 侧面 / 背面：回到完整构图。
- 自动旋转：默认关闭，可手动开启；页面不可见时暂停绘制。
- 显示原画：与无水印的水墨版本对照。
- 保存当前视角：导出当前画面的 PNG，不含网页控件。
- 下载立体模型：导出仅包含熊猫的 GLB，排除灯光、地面和相机。
- 兼容系统减少动态效果设置：不自动开始旋转，视角切换立即完成。

## 验证

```sh
npm test
npm run check
npm run test:browser
```

`test:browser` 自启随机端口的只读服务与独立无登录浏览器，执行后自动清理测试服务和浏览器，不接管现有用户会话。

浏览器测试优先使用 macOS 已安装的 Google Chrome；其他环境可执行 `npx playwright install chromium`，或设置 `PLAYWRIGHT_EXECUTABLE_PATH` 指向已有 Chromium。

覆盖：
- 真正的三维边界、关键部件、有限顶点/单位法线、曲面贴合、共享资源释放。
- 相机构图、不同角度、服务路径/编码/遍历隔离。
- 实际 WebGL 绘制、拖拽、缩放、四个视角、原画显隐、自动旋转启停。
- PNG 实际下载、GLB 二进制格式与内容、下载模型重新加载。
- 桌面 resize、手机布局、减少动态效果、无远程资源请求。
- 编码失败的可见反馈和恢复、WebGL 上下文丢失及刷新恢复。

## 腹部 Logo 还原

2026-10-27 修正了初版圆管替代图案与悬空短管的问题：

- 删除手绘近似的圆管、额外的抬高跨线段和突起节点，改用原 `LoomOS-panda-ink-clean.svg` 中的 104 条图案路径。
- 保留斜切轮廓、中心芯片引脚和四格、节点、原始矢量色块；保留左上/右下金色覆盖、右上/左下青绿覆盖的原图层顺序。
- 先细分宽三角形，再投影到腹部曲面；薄浮雕的表面间距为模型单位 0.012–0.02024，无悬空短管。
- 背景遮罩和色块也按原 SVG 图层顺序保留，不再用光滑圆管代替原图细节。
- 没有新增贴图或远程资源，GLB 中包含所有 Logo 网格和材质。

如未来更新了正面 SVG，检查图案区域后重新编译：

```sh
npm run build:emblem
npm test
npm run test:browser
```

编译器使用源文件 SHA-256 记录来源；路径数改变时会要求人工检查选区，而不是静默截取错误内容。编译后的数据随源码保存，正常预览不需要运行编译器。

这里保留的是现有 SVG 已有的矢量细节，而非从 PNG 中恢复被矢量化简化掉的纸张微纹理。熊猫其他造型和材质未改动。

## 参考视频的体积与毛绒调整

输入参考是用户提供的 8 秒、720×720 正面/小角度转头视频，抽帧记录见 `evidence/video-reference/`。视频没有完整 90° 侧视，不能据此宣称精确恢复全部三维尺寸。

- 直接调整头颅、躯干和四肢的实际三维体积，而非镜头缩放或整体拉伸。
- 口鼻前突融入同一头部网格，眼圈、鼻口和腹部 Logo 均由共享曲面函数重新定位。
- 头顶卷毛改为有圆形截面、逐渐收细的立体卷毛，不再使用薄片轮廓。
- 约 45,500 根短毛以两个实例批次呈现；使用切向梳理，不把全身法线拉成刺猬。
- 微法线纹理由本地代码确定性生成；不请求远程贴图。所有使用法线贴图的部件都有显式切线，便于 GLB 一致导出。
- 由原 Logo 路径生成占用检测，避免毛束覆盖刚还原的图案；原 SVG 数据和覆盖顺序未改动。
- GLB 包含短毛实例和内嵌纹理，使用 `EXT_mesh_gpu_instancing`。已在 Three.js GLTFLoader 中回读验证，未宣称在所有 DCC/查看器中兼容。

这仍然是实时、程序化的毛绒公仔风格原型，不是参考视频的影视级毛发复刻；没有新增视频里的转头、眨眼或毛发动力学。

## 这一版的边界

- 是程序化造型原型，保留原图的米白/炭黑配色、头顶卷毛、表情与腹部图案；不是原画的逐像素三维复刻。
- 侧面和背面是根据正面参考补充的设计，并非从 SVG 自动恢复。
- 材质为哑光短毛绒效果；没有声称还原原图水墨/纸张笔触。
- 无骨骼绑定、说话/走路等角色动画；自动旋转属于展示镜头运动。
- 分件网格有交叠，不保证水密，不能直接作为合格 3D 打印模型。
- 未做真机手机 GPU 验收、发布/部署或集成到 Loom OS 设备运行时。
- 原始 PNG/SVG、现有 Lua 代码和其他未提交工作保持不动；没有提交、推送或发布。
